# The Exchange

Website for the Reading, Pennsylvania buyer on Instagram at [@the.exchange610](https://www.instagram.com/the.exchange610/).

The page follows the approved layout: chrome wordmark in the header and footer, tall purple-to-blue `THE EXCHANGE`, white script `Buy, Sell, Trade`, and an original 3D arrangement of gold, a phone, and a sneaker. There is no circular badge, no background light beams, and no street address.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:4317/the-exchange-website/](http://127.0.0.1:4317/the-exchange-website/).

## Static export

```bash
npm run build
```

`next build` writes the site to `out/`. The copy in `docs/` is that export plus `.nojekyll`, ready for GitHub Pages on the `main` branch, folder `/docs`.

Intended public URL after Pages is enabled:

https://joeypbrrr.github.io/the-exchange-website/

## What is not on the page

No street address and no phone number. Public search did not tie a full address or phone to this Instagram account without conflicting with other businesses. Contact is the Instagram profile only.
